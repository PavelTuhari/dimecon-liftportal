Снимки экрана

Выводы

  • после загрузки паспортной таблицы подбор считает по ней, а не по оценке с запасом 15 %
  • зоны подачи и коэффициенты из формы сразу меняют сумму заказа
  • IBAN, код НДС и подпись руководителя печатаются в счёте, срок оплаты берётся из настроек
  • домен проверяется по DNS и по ответу сайта, подсказки по записям выдаются автоматически
  • то же самое доступно скриптами: отчёт готовности, загрузка таблиц, прайс, реквизиты, домен, ERP
Ограничения испытаний.
  • Проверка домена выполняется с сервера платформы: если запись DNS ещё не разошлась, проверку нужно повторить позже.
  • Сертификат HTTPS для своего домена выпускается на сервере после успешной проверки — это отдельный шаг администратора платформы.
  • Доступы к OfficePlus и Oracle на стенде не заполнены: скрипт обмена показывает, что подключение не настроено, а не работает вхолостую.
