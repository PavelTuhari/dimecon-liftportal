Oracle ERP OfficePlus · контрагенты напрямую

Чтение справочника контрагентов и оборотов из базы ERP. Запросы построены по схеме вашего проекта: TMS_ORG + TMS_UNIVERS (TIP='O'), обороты — по VMDB_ST201D и TMDB_DOCS (SYSFID 12280), учётные записи — PAPI_PARTNER.

Свой SQL вместо штатного запроса Колонки name / codfiscal / adress / gr1 / bank / cod распознаются автоматически. Пагинация по ROWNUM добавляется сама.

ERP работает на Oracle 11g, а thin-режим драйвера поддерживает только 12.1+. Поэтому для 11g выбирайте thick и укажите каталог Instant Client на сервере платформы.

Файловая выгрузкаработает сейчас: CSV/XLSX из любой CRM, ручной или регулярный импорт
REST-обменработает сейчас: чтение заявок и каталога, создание расчётов по ключу API

Oracle напрямуюадаптер готов: запросы по схеме TMS_ORG / TMS_UNIVERS / PAPI_PARTNER; нужны DSN, пользователь и пароль

Первые три сценария работают без доработок кода. Последние два настраиваются после предоставления доступа — кошелька Oracle либо возможности слать вебхуки.
